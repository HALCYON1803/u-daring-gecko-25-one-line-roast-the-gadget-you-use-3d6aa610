## How it works

`main.ts` writes that single line to `/output/entry.txt`, where the
sealed gate scorer reads it. The gate requires UTF-8 text of 1 to 200
characters, not only white space — this entry is 61 characters, one line.

Run locally:

```sh
node main.ts
cat /output/entry.txt
```
